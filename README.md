# BoxGiro · TV fácil

Landing page do produto **BoxGiro** — a TV fácil para toda a família.

## Estrutura do projeto

- `index.html` — página principal
- `boxgiro.mp4` — vídeo de demonstração
- `apk.json` — pacote da aplicação
- `poster.jpg`, `thumb.jpg`, `produto.webp` — imagens de marketing
- `ecras/` — capturas de ecrã da interface (início, jogos, rádio, etc.)

## Como visualizar

Abra o `index.html` no browser, ou publique com **GitHub Pages**.

## Publicar com GitHub Pages

1. Settings → Pages
2. Source: Deploy from a branch
3. Branch: `main` / root
4. Save

A página ficará em: `https://nelson325-cyber.github.io/boxgiro-tv-facil/`

## Nota

Os ficheiros de media (imagens, vídeo e `apk.json`) devem ser carregados manualmente via interface do GitHub (**Add file → Upload files**) ou com `git push` local.

Depois de carregar todos os ficheiros, ative o GitHub Pages para publicar o site.
